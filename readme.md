# 百度贴吧黑莓10原生版

## 说明

采用cascade框架 遵循黑莓UI设计准则

不会做的功能：发帖、回复（封号概率太大）

正常工作：账号切换、看帖、接受和查看回复与提及

这是越狱软件，要安装请先将您的黑莓越狱

仅供学习使用，禁止倒卖

欢迎加入 BlackberryPhonix QQ 交流群：892633534
